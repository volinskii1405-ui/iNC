# Горизонт событий

Маленькая инкрементальная игра про чёрную дыру для терминала, написана на C.
Начинаешь микро-дырой, которая едва тянет космическую пыль, а заканчиваешь
тем, что схлопываешь всю Вселенную. Прохождение занимает около 5 минут.

## Сборка и запуск

```sh
make
./blackhole
```

Без `make`:

```sh
cc -O2 -o blackhole src/main.c src/game.c -lm
```

Нужен терминал с поддержкой UTF-8 и ANSI-цветов размером от 80×28.
Работает на Linux и macOS. На Windows собирается MinGW
(`gcc -O2 -o blackhole.exe src/main.c src/game.c`) и запускается в Windows Terminal.

## Управление

| Клавиша  | Действие                                        |
|----------|-------------------------------------------------|
| `Пробел` | затянуть материю (клик)                         |
| `1`–`7`  | поглотить объект: пыль, астероид, … галактику   |
| `A`–`J`  | купить улучшение                                |
| `Z`      | поймать пролетающую блуждающую звезду           |
| `0`      | схлопнуть Вселенную, когда хватит массы         |
| `Q`      | выход                                           |

Клавиши работают и в русской раскладке.

## Как играть

- Объекты дают массу каждую секунду; каждый следующий объект того же типа дороже на 14%.
- Улучшения умножают доход отдельных объектов или всего сразу. «Релятивистские джеты»
  добавляют к каждому клику 10% дохода в секунду.
- Примерно раз в 30–50 секунд мимо пролетает блуждающая звезда: успей нажать `Z`
  за 8 секунд и получишь крупный бонус.
- Цель — накопить 50M массы и нажать `0`.

## Структура

- `src/game.c`, `src/game.h` — логика и баланс игры (без ввода-вывода).
- `src/main.c` — терминальный интерфейс, анимация аккреционного диска, ввод.
