# Горизонт событий

Инкрементальная игра про чёрную дыру с графикой, написанная на C++ и [raylib](https://www.raylib.com/).
Начинаешь микро-дырой, которая едва тянет космическую пыль, а заканчиваешь тем, что
поглощаешь всю Вселенную. Прохождение занимает около 9 минут.

## Что есть в игре

- Чёрная дыра на шейдере: аккреционный диск с доплеровской асимметрией, линзированная
  арка диска над тенью, фотонное кольцо. Звёзды фона искривляются гравитационной линзой.
- 10 объектов: пыль, астероиды, луны, планеты, газовые гиганты, звёзды, нейтронные звёзды,
  звёздные скопления, галактики, сверхскопления. Купленные объекты прилетают к дыре и
  растягиваются приливными силами. Покупка по одному, по 10 или на все деньги.
- Вехи: 10, 25, 50 и 100 объектов одного типа умножают их доход.
- Дерево прокачки на 31 узел в четырёх ветках:
  **Гравитация** (клик, криты, комбо, резонанс, гравитационная волна),
  **Аккреция** (множители дохода, пищевая цепочка),
  **Космос** (кометы, перехват, метеоритный дождь, сверхновая, скидки),
  **Тёмная материя** (способности и особые бонусы за вторую валюту).
- Тёмная материя — вторая валюта: даётся за кометы, достижения, ранги, победы над
  соперником, метеоры и идеальные клики.
- Способности с перезарядкой: **Q** — время течёт втрое быстрее, **W** — клики ×3,
  **E** — белая дыра (мгновенно 90 секунд дохода).
- События:
  - золотые кометы — поймай мышкой;
  - звёздная вспышка — один тип объектов ×5 на 20 секунд;
  - **чёрная дыра-соперник** крадёт 2% массы в секунду, пока её не забьёшь кликами;
  - метеоритный дождь — лови метеоры;
  - «Безумие» сверхновой — доход ×7.
- Резонанс: кольцо сжимается к горизонту, клик в момент, когда оно золотое, даёт ×3.
- Перехват: можно кликать по падающим объектам.
- Криты с тряской экрана, комбо, 21 достижение, 7 рангов, процедурные звуки.
- Финал: коллапс Вселенной и новый Большой взрыв с итоговой статистикой.

## Управление

| Действие                 | Как                                       |
|--------------------------|-------------------------------------------|
| Затянуть материю         | клик по чёрной дыре или `Пробел`          |
| Купить объект            | клик по карточке слева или `1`–`9`, `0`   |
| Сколько покупать         | кнопка над объектами или `B`              |
| Дерево прокачки          | кнопка справа или `T` (`Esc` закрывает)   |
| Способности              | `Q`, `W`, `E` или кнопки внизу            |
| Кометы, метеоры, соперник| клик по ним                               |
| Поглотить Вселенную      | кнопка внизу или `Enter`                  |
| Звук вкл/выкл            | `M`                                       |
| Полный экран             | `F` или `F11`                             |

## Сборка

Нужны CMake 3.16+, компилятор C++17 и dev-пакеты X11/OpenGL. raylib 5.5 скачивается
и собирается автоматически.

```sh
# Ubuntu / Debian
sudo apt install build-essential cmake git libx11-dev libxrandr-dev libxinerama-dev \
    libxcursor-dev libxi-dev libgl1-mesa-dev libasound2-dev

cmake -S . -B build
cmake --build build -j
./build/event_horizon
```

Шрифты DejaVu встраиваются в бинарник при сборке, так что игра — один файл.

## Структура

- `src/Game.cpp`, `src/Game.hpp` — логика и баланс, без графики.
- `src/main.cpp` — отрисовка, интерфейс, эффекты, дерево прокачки.
- `src/Shaders.hpp` — шейдер чёрной дыры.
- `src/Audio.cpp` — синтез звуков.
- `tools/sim.cpp` — симулятор баланса: бот проходит игру с заданной частотой кликов
  (`cmake --build build --target balance_sim && ./build/balance_sim 4 0.8`).
- `assets/fonts` — шрифты DejaVu Sans и их лицензия.
