# Горизонт событий

Инкрементальная игра про чёрную дыру с графикой, написанная на C++ и [raylib](https://www.raylib.com/).
Начинаешь микро-дырой, которая едва тянет космическую пыль, а заканчиваешь тем, что
поглощаешь всю Вселенную. Прохождение занимает около 5 минут.

## Что есть в игре

- Чёрная дыра на шейдере: аккреционный диск с доплеровской асимметрией, линзированная
  арка диска над тенью, фотонное кольцо. Звёзды фона искривляются гравитационной линзой.
- 7 объектов для поглощения: пыль, астероиды, луны, планеты, звёзды, нейтронные звёзды,
  галактики. Купленные объекты прилетают к дыре и растягиваются приливными силами
  (спагеттификация).
- Дерево прокачки на 18 узлов в трёх ветках:
  **Гравитация** (клик, криты, комбо, гравитационная волна),
  **Аккреция** (множители дохода),
  **Космос** (кометы, безумие сверхновой, скидки, излучение Хокинга).
- Плюшки: криты с тряской экрана, комбо-множитель за быстрые клики, золотые кометы,
  которые нужно ловить мышкой, режим «Безумие» (доход ×7), гравитационные волны,
  14 достижений (каждое даёт +2% дохода), ранги дыры, процедурные звуки и гул космоса.
- Финал: коллапс Вселенной и новый Большой взрыв с итоговой статистикой.

## Управление

| Действие                 | Как                                    |
|--------------------------|----------------------------------------|
| Затянуть материю         | клик по чёрной дыре или `Пробел`       |
| Купить объект            | клик по карточке слева или `1`–`7`     |
| Дерево прокачки          | кнопка справа или `T` (`Esc` закрывает) |
| Поймать комету           | клик по комете                         |
| Поглотить Вселенную      | кнопка внизу или `Enter`               |
| Звук вкл/выкл            | `M`                                    |
| Полный экран             | `F` или `F11`                          |

## Сборка

Нужны CMake 3.16+, компилятор C++17 и dev-пакеты X11/OpenGL. raylib 5.5 скачивается
и собирается автоматически.

```sh
# Ubuntu / Debian
sudo apt install build-essential cmake git libx11-dev libxrandr-dev libxinerama-dev \
    libxcursor-dev libxi-dev libgl1-mesa-dev libasound2-dev

cmake -S . -B build
cmake --build build -j
./build/event_horizon
```

Шрифты DejaVu встраиваются в бинарник при сборке, так что игра — один файл.

## Структура

- `src/Game.cpp`, `src/Game.hpp` — логика и баланс, без графики.
- `src/main.cpp` — отрисовка, интерфейс, эффекты, дерево прокачки.
- `src/Shaders.hpp` — шейдер чёрной дыры.
- `src/Audio.cpp` — синтез звуков.
- `tools/sim.cpp` — симулятор баланса: бот проходит игру с заданной частотой кликов
  (`cmake --build build --target balance_sim && ./build/balance_sim 5 1`).
- `assets/fonts` — шрифты DejaVu Sans и их лицензия.
