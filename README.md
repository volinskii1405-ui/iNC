# Горизонт событий

Инкрементальная игра про чёрную дыру с графикой, написанная на C++ и [raylib](https://www.raylib.com/).
Около 10 минут: четыре вселенные, заходы по 30 секунд.

## Как играть

Игра состоит из **заходов**. Чёрная дыра летит за курсором по бесконечному космосу
и засасывает всё, что меньше неё: пыль, астероиды, кометы, луны, планеты, газовые гиганты,
звёзды, скопления, галактики, сверхскопления, квазары, Великую стену и пузыри Хаббла. Чем больше съел, тем крупнее дыра и тем
крупнее добыча. Объекты с красной пунктирной обводкой пока не по зубам.

Дыра испаряется (излучение Хокинга): заход длится **не больше 30 секунд**. Узлы времени
доводят таймер до 30 секунд, а часы только возвращают отнятое опасностями. Мешают:
- **антиматерия** — отнимает время при касании;
- **пульсары** — вращающиеся лучи бьют по времени;
- **дыры-соперники** — крупные охотятся на тебя, мелких можно съесть ради большого бонуса.

Помогают:
- **часы** (+время);
- **тёмная материя** (вторая валюта);
- **золотые кометы** (×20 массы);
- **пир** — комбо за быстрые поглощения;
- **артефакты**: магнит (притяжение ×2.5), сверхновая (раскалывает всё крупное вокруг на еду),
  хроносфера (останавливает время и защищает), удвоитель (масса ×2).

Внутри захода:
- **Эволюция**: дыра выросла на ступень — игра на паузе, выбираешь одну из 3 карт-усилений
  до конца захода (13 карт трёх редкостей: притяжение, спутник, цепная реакция, сверхновая,
  жадность, броня, острые зубы…). Каждый заход получается разным.
- **Голод → Гиперпоглощение**: шкала голода копится от добычи. Заполнилась — несколько
  секунд можно есть объекты намного крупнее себя, притяжение ×2, масса ×2.
- **Аномалия захода**: метеоритный шторм, золотая лихорадка, тёмная туманность,
  нашествие соперников, звездопад, спокойный сектор, пульсарное поле.
- **Два задания** на каждый заход (съешь крупное, не получай урон, разгони пир…):
  за каждое — масса и тёмная материя.

Между заходами массу тратят в **созвездии прокачки**: 89 узлов в шести ветках. Сначала у узлов
333 уровня, и каждая новая вселенная поднимает пределы, всего до 801 уровня:
- **Гравитация**: притяжение, скорость, рывок, гравитационный коллапс, что можно съесть.
- **Рост**: стартовый размер, рост за заход, спутники — мини-дыры, которые кружат рядом и едят мелочь.
- **Время**: таймер до 30 секунд, квантовые часы, защита, голод, гиперпоглощение, выбор из 4 карт.
- **Богатство**: ценность добычи, криты, пир, сложный процент.
- **Космос**: плотность, крупные объекты, цепные реакции звёзд, метеоритные рои, соперники.
- **Тёмная материя**: особые бонусы за вторую валюту.

Цель — открыть узел «Ядро Вселенной», найти Ядро в космосе по стрелке и **откусить** его:
кусать можно, когда дыра хотя бы вдвое меньше Ядра. Пока кусаешь, испарение идёт вдвое
медленнее.

Вселенных четыре: **Млечная**, **Кристальная**, **Огненная** и **Квантовая пена**. У каждой
свои цвета, объекты в ней ценнее, а Ядро крупнее. Съел Ядро — переходишь в следующую,
прокачка сохраняется, а пределы уровней в созвездии растут на 2.

## Управление

| Действие               | Как                                        |
|------------------------|--------------------------------------------|
| Вести дыру             | мышь                                       |
| Рывок                  | `Пробел` или правая кнопка мыши (после прокачки) |
| Гравитационный коллапс | `Q` (после прокачки)                       |
| Выбор карты эволюции   | клик по карте или `1`–`4`                  |
| Созвездие              | клик — купить, перетаскивание — двигать, колесо — масштаб |
| Начать заход           | кнопка или `Пробел` / `Enter`              |
| Звук вкл/выкл          | `M`                                        |
| Полный экран           | `F` или `F11`                              |

## Сборка

Нужны CMake 3.16+, компилятор C++17 и dev-пакеты X11/OpenGL. raylib 5.5 скачивается
и собирается автоматически.

```sh
# Ubuntu / Debian
sudo apt install build-essential cmake git libx11-dev libxrandr-dev libxinerama-dev \
    libxcursor-dev libxi-dev libgl1-mesa-dev libasound2-dev

cmake -S . -B build
cmake --build build -j
./build/event_horizon
```

Шрифты DejaVu встраиваются в бинарник при сборке, так что игра — один файл.

## Структура

- `src/Game.cpp`, `src/Game.hpp` — логика и баланс, без графики.
- `src/main.cpp` — отрисовка космоса, интерфейс захода, созвездие прокачки, эффекты.
- `src/Shaders.hpp` — шейдер чёрной дыры.
- `src/Audio.cpp` — синтез звуков.
- `tools/sim.cpp` — симулятор баланса: бот сам водит дыру и качается между заходами
  (`cmake --build build --target balance_sim && ./build/balance_sim 0.8 v`).
- `assets/fonts` — шрифты DejaVu Sans и их лицензия.
